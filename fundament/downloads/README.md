# Fundament — PDF ohne Datei-Upload

Artikel werden als PDF über den **Browser-Druckdialog** gespeichert:

- Auf der Artikel-Seite: **„Als PDF speichern (Drucken)“**
- Oder Link mit `?drucken=1` (öffnet Druckdialog automatisch)
- Im Druckdialog: Ziel **„Als PDF speichern“** wählen

Keine statischen `df1.pdf` / `df2.pdf` im Repo nötig.
